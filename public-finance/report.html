Report an error

Seen a number that does not match the printed budget? Tell us. Submitting opens a prefilled GitHub issue; every report is public, tracked, and feeds the correction queue. You will need a (free) GitHub account to press the final button.

Reports land as issues labelled data-error in the repository, where they can be checked against the source PDF and corrected upstream. Prefer email? The repository README lists maintainer contacts.
